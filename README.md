# Development of software applications for mobile devices

Лабораторні роботи курсу. Кожна лабораторна — повністю самостійний Expo-проєкт
у власній папці (свій `package.json`, `app.json`, залежності). Запускати їх
потрібно з відповідної підпапки, а не з кореня репозиторію.

## Лабораторні

| Папка | Опис |
| --- | --- |
| [`lab1-timer/`](./lab1-timer) | Таймер (Pomodoro) |
| [`lab2-movie-browser/`](./lab2-movie-browser) | Movie Browser — пошук фільмів через OMDb API, React Navigation |

## Як запустити конкретну лабораторну

```bash
cd lab2-movie-browser   # або lab1-timer
npm install
npx expo start
```

Деталі (змінні середовища, структура коду, корисні команди) — у `README.md`
всередині кожної папки.
